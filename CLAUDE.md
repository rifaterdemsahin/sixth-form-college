# Working agreement

- **One branch only: `main`.** After every change, commit straight to `main` and push. Don't create feature branches or PRs. Don't wait to be asked. Pushing to `main` triggers the GitHub Pages deploy.
- After editing `prerequisites.html`, re-export `prerequisites.pdf` (A4, print media) in the same commit.
- Keep `TASKS.md` in step: tick items off when they're done.
