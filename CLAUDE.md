# Working agreement

- **One branch only: `main`.** After every change, commit straight to `main` and push. Don't create extra feature branches. If the environment blocks direct pushes to `main`, push to the one session branch, then open a PR and merge it straight away. Don't wait to be asked. Pushing to `main` triggers the GitHub Pages deploy.
- After editing `prerequisites.html`, re-export `prerequisites.pdf` (A4, print media) in the same commit.
- Keep `TASKS.md` in step: tick items off when they're done.
