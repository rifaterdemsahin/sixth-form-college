# Working agreement

- **Always commit and merge.** After every change: commit on the working branch, push, open a PR into `main` and merge it straight away. Don't wait to be asked. Pushing to `main` triggers the GitHub Pages deploy.
- After editing `prerequisites.html`, re-export `prerequisites.pdf` (A4, print media) in the same commit.
- Keep `TASKS.md` in step: tick items off when they're done.
